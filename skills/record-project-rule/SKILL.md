# record-project-rule

在 `plan`、`test`、`implement` 過程中，確立的專案特有規則不屬於這個 `.github` 通用規則涵蓋範圍時觸發。

依 `.github/prompts/record-project-rule.prompt.md` 的提案 SOP 執行：提案給使用者 → 確認 → 判斷目標專案 → 寫入檔案 → 登記到共用工作區設定 → 重新讀取核對。
