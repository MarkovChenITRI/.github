## 使用方式

1. SOP2 的施工完成物、施工簽核、殘餘風險與偏差回寫，仍以 blueprint 為真相源，不在此目錄維護。
2. 只有進入 SOP3 後，才在此目錄的 work order 內集中維護驗收結論、證據包、缺口清單、blocker、closure state 與重新派工。
3. 若驗證失敗但屬施工缺口，回到同一份 work order 重新派工；若是否定 blueprint 前提，才回上游重開規劃。
4. 任一 owner、完成條件、驗證方式、closure criteria 缺失，視為不可簽核。
