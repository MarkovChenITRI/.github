# 計劃書敘述段落格式

計劃書固定路徑 `<專案資料夾>/.github/proposals/<name>.md`，依序包含四個段落：目標市場需求、產品開發與技術服務、計畫架構與實施方法、計畫時程與查核點。這份文件定義前兩段——純敘述、沒有圖表語法規則——的內容範圍；後兩段的樹狀圖、時程圖與查核點表格規則，定義在 `proposal-schedule-format.instructions.md`。

## 目標市場需求

具體寫出這個計畫鎖定的使用者或客群是誰、他們目前有什麼沒被滿足的需求、這個需求的規模或急迫性有什麼依據（例如既有數據、訪談紀錄、競品缺口）。判斷性的詞（例如「市場很大」「需求很急迫」）一律換成陳述依據的講法，讓不同時間讀到的人都能做出同一個判斷（例如把「市場很大」換成「同類產品去年成長 40%，目前還沒有廠商鎖定這個客群」）。

## 產品開發與技術服務

具體寫出這個計畫要開發的產品或服務範圍、預計採用的技術方案、跟既有產品或服務的差異。每個技術方案的選擇都附上為什麼選這個方案，不是只列方案名稱。
