# 軟體開發與維運技能通用準則

implement 技能處理程式撰寫與建置、發布與部署、運行與監控。每次異動前先讀取上層資源（規格書）確認邊界；異動後若模組的 What、How、Where 有變，回到規格書更新對應段落。

程式撰寫與建置的四層放置規則與依賴方向，詳見 `code-build.instructions.md`；發布與部署的流程詳見 `release-deploy.instructions.md`；運行與監控的處理流程詳見 `operate-monitor.instructions.md`。
